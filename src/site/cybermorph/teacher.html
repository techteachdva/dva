How to set up the Google Form (once)
  1. Make a Google Form with one Short answer question: "Paste your CyberMorph code". Turn on "Collect email addresses" if you want names checked.
  2. In the form's ⋮ menu, choose Get pre-filled link. Type CODE in the answer box and press Get link, then Copy link.
  3. Paste that link in the box above. The game swaps CODE for each student's code, so they only press Submit.
  4. Each week, open the responses in Sheets, copy the code column, and paste it at the top of this page.
